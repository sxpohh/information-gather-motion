# 文案与镜头

先写观众需要理解的事，再安排动作。开场点清产品类别；中段每个功能说明能做什么、减少哪一步麻烦；结尾留下产品名与使用理由。避免只说精致、智能、高效而没有画面证据。

| 阶段 | 动作 | 编排判断 |
|---|---|---|
| 开场 | 两张真实页面前后交错、透视入场 | 标题一句话说明产品用途，截图提供整体认识 |
| 功能交接 | 前一页退后，当前页接到前景 | 一个动作引导视线，不必每次硬切或换背景 |
| 重点 | 转正、推近截图中的核心区域 | 列表要能读、表格要对准实际列、图表要保留必要坐标 |
| 多重点 | 沿同一张原图平移 | 只用于相关的两个区域，避免漫无目的扫屏 |
| 结尾 | 双机回到同一空间 | 让功能回到一个完整产品，品牌与使用理由落版 |

模板里每次交接为1.1秒，每次推近为0.85秒；hold是推近后的停留时间。这是可用起点，不是所有产品必须同节奏。先做最难读的镜头，确定截图与字号能承载信息，再填完其余场景。

正文要配音时先定声音节奏，再调hold和字幕时间。大标题与底部字幕不要逐字重复；正文语气由产品和受众决定。推荐口吻可以自然一点，发布口吻可以克制一点，不把某款产品的固定话术套到所有产品。

图像不含所需内容时，换素材或调整文案，不让矩形框代替实际功能。演示菜单入口可以说有入口；未执行操作不能说已完成操作。虚构示意图始终标明示意，不混入真实产品素材清单。
